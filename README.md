# Customer Behavior Analysis

## Overview
An end-to-end data analytics project analyzing customer shopping behavior 
to uncover purchasing trends, segment customers, and generate actionable 
business insights using Python, SQL, and Power BI.

> **Note:** This project was implemented by following a guided tutorial.  
> All analysis, queries, and dashboard were built hands-on by me.

## Tech Stack
| Tool | Purpose |
|------|---------|
| Python (Pandas, NumPy, Matplotlib, Seaborn) | Data cleaning & EDA |
| MySQL / MS SQL Server | Business queries & data modeling |
| Power BI | Interactive dashboard |
| Jupyter Notebook | Analysis environment |

## Project Workflow
1. **Data Preparation** — Cleaned and transformed raw customer data using Python
2. **SQL Analysis** — Loaded data into SQL, wrote queries to answer business questions
3. **Power BI Dashboard** — Connected SQL database to Power BI, built interactive visuals
4. **Report & Presentation** — Summarized key findings and business recommendations

## Key Business Questions Answered
- Which customer segments generate the most revenue?
- What are the top-selling product categories?
- How does customer loyalty affect purchase frequency?
- What factors drive repeat purchases?

## How to Run
1. Clone the repo:
```bash
   git clone https://github.com/Rakesh-create2003/Customer_Behavior_Analysis.git
```
2. Install dependencies:
```bash
   pip install pandas numpy matplotlib seaborn sqlalchemy
```
3. Open the notebook:
```bash
   jupyter notebook customer_behaviour_analysis.ipynb
```
4. Load data into SQL and connect to Power BI (see notebook for steps)
